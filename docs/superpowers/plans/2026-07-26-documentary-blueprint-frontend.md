# Documentary Blueprint — Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add documentary run support to the operator UI — a footage storyboard
variant with candidate swapping, provenance badges, failed-scene recovery,
channel sourcing settings, and a credits preview — without changing behaviour
for existing AI-visual runs.

**Architecture:** The storyboard response gains a `profile` discriminator. The
existing `StoryboardScene` type gains an optional `footage` sub-object, so every
current consumer keeps compiling untouched. A `StoryboardSceneCard` sibling
renders footage scenes; the shared grid picks a card by profile.

**Tech Stack:** Vite + React 19 + TypeScript, TanStack Query/Router, Zustand,
Tailwind, Vitest, Playwright, Storybook, orval.

**Repo:** `/Users/chuckz/Code/29SignalsDev/***REMOVED***-frontend` — a **separate
repo** from the backend. All paths below are relative to its root.

**Prerequisite:** the backend pipeline plan
(`2026-07-26-documentary-blueprint-pipeline.md`) must be merged and
`schema.yaml` regenerated from its OpenAPI export, or `pnpm orval` produces
none of the new endpoints.

**Pairs with:**
`docs/superpowers/specs/2026-07-26-longform-documentary-frontend-brief.md`

   hand-edited.

   `useStoryboard` calls `getStoryboard` from **this** layer.

const ARCHIVAL_PROVIDERS = new Set(["wikimedia", "openverse", "archive_org"]);

export type ProvenanceTone = "ai" | "archival" | "stock" | "none";

export const provenanceTone = (
	footage: SceneFootage | null,
): ProvenanceTone => {
	if (footage === null) {
		return "none";
	}
	if (footage.source === "ai_flux") {
		return "ai";
	}
	return ARCHIVAL_PROVIDERS.has(footage.source) ? "archival" : "stock";
};

export const provenanceLabel = (footage: SceneFootage | null): string => {
	const tone = provenanceTone(footage);
	if (tone === "ai") {
		return "AI generated";
	}
	if (tone === "archival") {
		return "Archival";
	}
	return tone === "stock" ? "Stock" : "";
};

export const isAiFallback = (scene: StoryboardScene): boolean =>
	scene.footage?.source === "ai_flux";
```

import {
	useMutation,
	useQueryClient,
	type UseMutationResult,
} from "@tanstack/react-query";
import { selectCandidate } from "../../core/api/client";
import { queryKeys } from "../../core/api/query-keys";
import type { StoryboardResponse } from "../../core/api/types";

type SelectCandidateInput = {
	externalId: string;
	sceneIdx: number;
};

export const useSelectCandidate = (
	runId: string,
): UseMutationResult<StoryboardResponse, Error, SelectCandidateInput> => {
	const queryClient = useQueryClient();
	return useMutation({
		mutationFn: ({ externalId, sceneIdx }: SelectCandidateInput) =>
			selectCandidate(runId, sceneIdx, externalId),
		onSuccess: (): void => {
			void queryClient.invalidateQueries({
				queryKey: queryKeys.runs.storyboard(runId),
			});
		},
	});
};
```
